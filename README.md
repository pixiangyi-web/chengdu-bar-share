# chengdubarshare

成都酒吧规则加权总榜与热力分布网页。

## 内容

- 152 家酒吧完整排名，默认展示前 50 家
- 总分及专业、大众点评、小红书、本地、旅游/英文评分排序
- 人均、位置、类型、特色标签及大众点评店铺链接
- 可缩放热力地图与街区酒吧列表
- 桌面端和移动端响应式布局

## 使用

直接打开 `index.html`。页面通过 CDN 加载 Leaflet、Lucide 和字体，地图底图来自 OpenStreetMap，因此需要联网。

## 数据口径

本项目用于行业研究与传播观察。排名代表研究样本优先级，不等于个人口味榜；地图使用商圈级锚点，不作导航。
